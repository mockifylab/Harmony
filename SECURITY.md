Security Policy
Supported Versions

Harmony is currently in active development.

Version	Supported
1.0.x	Yes
Older versions	No

Security support applies to officially released versions of Harmony. Development builds and unofficial modifications may not receive security fixes.

Reporting a Security Vulnerability

If you discover a security vulnerability in Harmony, please do not disclose it publicly through GitHub Issues, discussions, pull requests, or other public channels before it has been investigated.

Please report security issues privately through the repository's GitHub security reporting feature:

Report a vulnerability

When reporting a vulnerability, please include as much of the following information as possible:

• A clear description of the vulnerability

• The affected Harmony version

• The Android version and device where the issue occurs

• Steps required to reproduce the issue

• The potential impact of the vulnerability

• Screenshots, logs, proof of concept code, or other relevant technical information, when available

Please avoid including personal information, account credentials, private tokens, or other sensitive data in your report.

What Happens After a Report

Once a security report is received, we will review the issue and determine whether it affects Harmony.

If the vulnerability is confirmed, we will work on an appropriate fix and may release a security update or other mitigation.

The reporter may be contacted for additional technical information if necessary.

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability.

Scope

This policy covers security vulnerabilities introduced or maintained within the Harmony project.

Harmony is based on the original Musify project by Valeri Gokadze and the Musify contributors. Security issues originating exclusively from upstream Musify, external plugins, third party services, content providers, or other dependencies may require reporting to the respective project or provider as well.

Responsible Disclosure

We ask security researchers and users to practice responsible disclosure and avoid publicly exposing vulnerabilities before a reasonable opportunity has been provided to investigate and address them.

Thank you for helping keep Harmony and its users safer.
